# Dashboard SPK Seleksi Influencer

## Deskripsi
Aplikasi Sistem Penunjang Keputusan untuk membantu proses seleksi penerimaan mitra Content Creator atau Influencer untuk Campaign Brand menggunakan metode Simple Additive Weighting (SAW).

## Tujuan
Membantu proses pemilihan influencer berdasarkan beberapa kriteria penilaian sehingga menghasilkan rekomendasi alternatif terbaik.

## Metode
Simple Additive Weighting (SAW).

## Kriteria Penilaian
1. Engagement Rate (Benefit) - 25%
2. Kesesuaian Audiens (Benefit) - 25%
3. Biaya Kerja Sama (Cost) - 20%
4. Kualitas Konten (Benefit) - 15%
5. Brand Safety dan Kredibilitas (Benefit) - 15%

## Teknologi
- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Cara Menjalankan Aplikasi

1. Aktifkan virtual environment.
2. Instal library menggunakan:

   pip install -r requirements.txt

3. Jalankan aplikasi menggunakan:

   streamlit run app.py

4. Buka alamat lokal yang ditampilkan oleh Streamlit.
